# ハングル→カタカナ 発音変換

韓国語（ハングル）を、**実際に聞こえる音**のカタカナに変換するツールです。

👉 **https://nam9514-cpu.github.io/hangul-katakana/**

- 連音化・鼻音化・流音化・激音化・口蓋音化・濃音化・有声音化を反映（例：감사합니다 → カムサハムニダ）
- K-POPの歌詞もOK。発音が変わるところをピンクで表示
- [よく使う韓国語フレーズの読み方一覧](https://nam9514-cpu.github.io/hangul-katakana/p/)
- 入力した文字はサーバーに送られません（ブラウザ内で変換）
